Election Strategy Simulation

GOTV vs Persuasion · Python · NumPy · NetworkX · Matplotlib

An agent-based simulation exploring how campaign budgets for voter turnout versus persuasion interact with voter networks.

Source on GitHub · private access
Reading the heatmaps. Horizontal axis: Democratic GOTV budget share. Vertical axis: Republican GOTV budget share. GOTV means get out the vote: mobilizing turnout rather than persuading voters. Vote margin is Republican minus Democratic; positive values favor Republicans, negative values favor Democrats. The other heatmap counts simulated abstained voters.

Michigan · Baseline network

Each looping heatmap follows saved Weeks 0–8 as both parties allocate their campaign budgets between turnout efforts and persuasion. The abstention panel changes visibly from yellow to purple as simulated non-voting decreases. The vote-margin panel changes much less visibly on its absolute scale. Color scales stay fixed across weeks within each animation. Use Static view to inspect the matching Week 8 snapshot.

Michigan · Siloed network

The same two outputs for the alternate siloed network profile. Compare how the budget-strategy landscape changes with network structure; each animation retains its own fixed color scale.

What these outputs show

The animations are regenerated from saved legacy simulation checkpoints, with 41 frames interpolating between weekly snapshots. They show model behavior under the saved assumptions, not validated election forecasts.

The current Python model source and the legacy checkpoint corpus are separate. Rebuilding these visuals reads saved summaries; it does not rerun the current model. Graph neural election forecasting is a future research roadmap, not a demonstrated result of these charts.

The source repository is private and requires authorized GitHub access. All showcase images are hosted directly on this website. View image provenance and checksums ↗
