Agent Demand Network (ADN)

2026 – Present

A decision-intelligence and commercial knowledge-and-experience layer for AI agents choosing machine-usable software and services. ADN returns structured, progressively disclosed product intelligence and accumulates verified runtime observations plus agent-reported experience to improve future decisions.

Core loop: Find → Inspect → Use → Report → Better future decision.

Static facts such as capabilities, interfaces, pricing models, and documentation live alongside dynamic information such as reliability, latency, failures, benchmarks, and agent outcomes. Agents can contribute new assertions and update changing facts rather than forcing every future agent to rediscover the market from scratch.
